# Электроника (Electronics)

Схемотехника, трассировка печатной платы в **EasyEDA** и симуляция физических процессов прибора.

### Структура папки:

* 📁 **[easyeda](./easyeda/)** — исходные файлы схемы и платы в формате проекта EasyEDA.
* 📁 **[simulation](./simulation/)** — тепловой анализ планарного радиатора в CST Studio Suite и симуляция переходных процессов в Micro-Cap.
