# Раздел электроники (Electronics)

В данном разделе представлены файлы проектирования схемы, печатной платы и результаты симуляции физических процессов стенда.

Схема и плата выполнены в программе easy-eda. Симуляции проводились в программах micro-cap и cst studio suite.

---

## Структура раздела

* 📁 **[easy-eda](./easy-eda/)** — исходные файлы проекта печатной платы и схемы в формате .json EasyEDA.
* 📁 **[simulation](./simulation/)** — файлы теплового моделирования планарного радиатора в CST Studio Suite, схемы симуляции мягкого старта в Micro-Cap и подробный отчет по итерациям расчетов.
