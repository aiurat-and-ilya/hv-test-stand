# Механическая часть (КОМПАС-3D)

В этом разделе находятся файлы конструкции корпуса прибора, разработанные в системе **КОМПАС-3D**.

### Структура папки:

* 📁 **[enclosure](./enclosure/)** — исходные 3D-модели:
  * Общая сборка корпуса (`.a3d`).
  * Детали корпуса для печати/изготовления (`.m3d`).
  * Фурнитура (модели винтов, тактовых кнопок).
* 📁 **[images](./images/)** — скриншоты готовых 3D-моделей и деталей корпуса.
* 📁 **[drawings](./drawings/)** — чертежи деталей и сборочные единицы в формате `.cdw`.
* 📄 **[pcb.step](./pcb.step)** — 3D-модель печатной платы (STEP), импортированная для сопряжения и контроля зазоров в общей сборке.
