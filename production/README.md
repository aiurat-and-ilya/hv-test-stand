# Файлы для производства (Production)

В этом разделе собраны финальные файлы, необходимые для заказа печатной платы, закупки компонентов и сборки устройства.

### Содержимое папки:

* 📁 **[gerber](./gerber/)** — Gerber-файлы (проект платы, подготовленный для отправки на производство).
* 📁 **[drawings](./drawings/)** — сборочные и габаритные чертежи деталей в формате `PDF` для быстрого просмотра и печати.
* 📁 **[images](./images/)** — фотографии изготовленной платы (без компонентов и в сборе), а также тест замера выходного напряжения.
* 📄 **[bom.xlsx](./bom.xlsx)** — перечень элементов (BOM) со спецификациями и ссылками на компоненты в магазине «Чип и Дип» *(примечание: некоторые внешние ссылки со временем могли стать неактуальными)*.
